# Demos

This directory contains [VHS](https://github.com/charmbracelet/vhs) tape files (`.tape`) used to generate visual demonstrations of the project in action.

## Contents

*   `demo_run_server.tape`: Script for recording the server build and startup process.
*   `demo_testing_gif.tape`: Script for recording the testing pipeline output as a GIF.
*   `demo_testing_video.tape`: Script for recording the testing pipeline output as a video format.
*   `gifs/`: Directory intended to store the generated outputs from the `.tape` files.

To generate the demos, you must have `vhs` installed on your system. Run `vhs <filename>.tape` to produce the corresponding media file.
